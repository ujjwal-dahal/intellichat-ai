# IntelliChat AI

An intelligent AI assistant built to explore conversational AI, memory, document-based question answering, and agentic workflows.

## About the Project

IntelliChat AI is a learning project focused on building a feature-rich AI assistant using modern LLM application development tools.

The project explores how an AI assistant can manage conversations, remember previous interactions, answer questions from documents, use external tools, and provide real-time responses.

## Planned Features

- **Conversational Chatbot:** Interactive AI conversations.
- **Conversation Memory:** Maintain chat history across interactions.
- **Persistence:** Save conversation states and continue previous sessions.
- **Streaming:** Display AI responses in real time.
- **Document Chat (RAG):** Ask questions about uploaded documents.
- **Tool Calling:** Allow the AI assistant to use external tools.
- **MCP Integration:** Connect with tools and services through the Model Context Protocol.
- **Database Integration:** Store conversation history using SQLite.
- **Observability:** Trace and debug LLM workflows using LangSmith.
- **Chat Interface:** Build a simple user interface using Streamlit.

## Tech Stack

- Python
- LangGraph
- LangChain
- Streamlit
- SQLite
- LangSmith
- Large Language Models (LLMs)
